# wallet — ядро платёжного кошелька

Счета, пополнения, переводы и история операций в памяти.

## Решения
- **`Decimal` вместо `float`**: `0.1 + 0.2 != 0.3` недопустимо для денег. Суммы округляются до тиын (`ROUND_HALF_UP`).
- **Идемпотентность**: клиент передаёт `key`. Повтор запроса с тем же ключом (например, после таймаута сети) возвращает ту же транзакцию и не списывает деньги дважды.
- **Потокобезопасность**: проверка баланса и списание выполняются атомарно под `threading.Lock`. Тест запускает 100 параллельных переводов.
- **Журнал (ledger)**: каждая операция — неизменяемая запись, из которой можно восстановить историю счёта.

## Запуск
```bash
python3 -m unittest -v
```

```python
from wallet import Bank
bank = Bank()
a, b = bank.open_account(), bank.open_account()
bank.deposit(a, "1000")
bank.transfer(a, b, "250.50", key="order-42")
```
