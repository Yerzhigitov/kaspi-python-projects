# logstats — анализатор access-логов

CLI-утилита, которая по логу веб-сервера считает метрики, на которые смотрят дежурные инженеры.

```bash
python3 logstats.py sample.log --top 5
```
```
Запросов: 7 (битых строк: 1)
Статусы: {'2xx': 5, '5xx': 1, '4xx': 1}  |  5xx: 14.29%
Latency p50=40ms p95=900ms p99=900ms
Самые медленные эндпоинты:
  POST /api/pay                  avg=560ms  n=2
```

## Что внутри
- **Перцентили (nearest-rank)**: среднее скрывает медленные «хвосты», поэтому SLO формулируют через p95/p99.
- **Нормализация путей**: `/users/42` и `/users/7` → `/users/{id}`, чтобы метрики не дробились.
- **Устойчивость**: битые строки считаются, но не роняют анализ.
- **Потоковая обработка**: файл читается построчно, без загрузки целиком в память.

Формат строки: `2026-10-17T10:00:00 GET /api/pay 200 123ms`
